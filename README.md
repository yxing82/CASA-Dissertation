# Hierarchy-Crossing Migration and Neighbourhood Change in London

Code and reproducibility materials accompanying the MSc Urban Spatial Science dissertation submitted to the Centre for Advanced Spatial Analysis (CASA), University College London, 2026.

## Project overview

This dissertation examines whether hierarchy-crossing residential migration structures correspond with independently identified neighbourhood change in London. Rather than treating a directional migration pattern as evidence of gentrification by definition, the analysis separates the measurement of migration structure from the measurement of neighbourhood transformation and tests the relationship empirically.

The study uses 2011 and 2021 Census origin-destination migration data, a fixed deprivation hierarchy derived from the English Indices of Multiple Deprivation, and independent neighbourhood-change indicators. It also tests how results change when the deprivation ladder and geographical migration-system boundary are altered, before decomposing the coarse flow classification into more specific inflow- and outflow-based mechanisms.

## Research questions

1. To what extent do hierarchy-crossing migration structures correspond with independently identified neighbourhood ascent and gentrification subtypes?
2. How general is the proposed cascade structure across census periods and alternative deprivation and geographical reference frames?
3. Which combinations of inflow and outflow underlie the coarse cascade classification, and how do they correspond with specific gentrification subtypes?

## Analytical workflow

The reproducible workflow follows the logic of the dissertation:

```text
Raw Census OD, deprivation and geography data
                    |
                    v
        Geographical harmonisation
        2011 MSOA analytical frame
                    |
                    v
       Fixed deprivation hierarchy
                    |
                    v
      Hierarchy-crossing flow metrics
                    |
                    v
        Four-way flow typology
                    |
          +---------+---------+
          |         |         |
          v         v         v
   Correspondence  Frame    Mechanism
      testing    sensitivity decomposition
      (RQ1)        (RQ2)       (RQ3)
```

The main stages are:

1. **Data preparation and geographical harmonisation** — harmonise 2011 and 2021 migration data to a common 2011 MSOA geography and construct the deprivation reference frame.
2. **Flow measurement** — construct paired hierarchy-crossing inflow and outflow measures and the associated cascade/counter-flow metrics.
3. **Typology construction** — classify neighbourhoods according to directional dominance and cross-hierarchy migration intensity.
4. **Independent correspondence testing** — compare migration structures with IMD change and independently derived attribute-based gentrification indicators.
5. **Reference-frame sensitivity** — compare London-relative and national deprivation ladders, and closed versus open migration-system definitions.
6. **Mechanism decomposition** — separate the coarse Cascade-led category into inflow-driven, internally outflow-dominated and externally outflow-dominated profiles and compare these with gentrification subtypes.

## Key data sources

The analysis draws on the following sources:

- **2011 Census origin-destination migration data**: MF01EW, originally available at Output Area level and aggregated to the analytical MSOA geography.
- **2021 Census origin-destination migration data**: RM097, harmonised to the same 2011 MSOA analytical frame.
- **English Indices of Multiple Deprivation**: IMD 2010 provides the fixed baseline deprivation hierarchy; IMD 2019 is used as an independent neighbourhood-change outcome.
- **ONS geographical correspondences**: used to reconcile boundary changes between the 2011 and 2021 MSOA geographies.
- **Independent gentrification indicators**: comparisons with the attribute-based gentrification classifications developed by Yee and Dennett (2022).

Large source datasets are not necessarily stored in this repository. Where redistribution is inappropriate or impractical, the repository documents the original source and the preprocessing code required to reconstruct the analytical data.

## Analytical reference frames

Three reference frames are used to separate different sources of sensitivity:

| Frame | Migration flows | Deprivation hierarchy | Purpose |
|---|---|---|---|
| **A** | London-internal | London-relative | Baseline within-London comparison |
| **B** | London-internal | National | Isolates deprivation-ladder reclassification |
| **C** | London-internal + boundary-crossing | National | Isolates the effect of opening the migration-system boundary |

The comparison from **A to B** changes the deprivation ladder while holding the observed migration boundary fixed. The comparison from **B to C** retains the national ladder while adding migration between London and the rest of England.

## Main flow measures

For each MSOA and census period, migration is decomposed into four directional components relative to the fixed deprivation hierarchy:

- inflow from wealthier origins;
- outflow towards poorer destinations;
- outflow towards wealthier destinations;
- inflow from poorer origins.

Same-decile moves are retained in total migration counts but excluded from the directional hierarchy-crossing components. These elementary flows are used to derive the dissertation's cascade/counter-flow measures and the four-way neighbourhood typology.

## Reproducing the analysis

The final execution order will be documented in `docs/reproducibility.md` once the submission branch has been cleaned. In general, scripts should be run in numerical folder order:

```text
01_preprocessing
      -> 02_flow_metrics
      -> 03_correspondence
      -> 04_reference_frames
      -> 05_mechanisms
```

Some notebooks depend on intermediate files produced during preprocessing. Paths and dependencies are being standardised in the submission branch so that the workflow is easier to follow than the original exploratory research directory.
